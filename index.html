    Salvar artigo

    O artigo aparece na lista na hora e fica pronto em 1 a 2 minutos.

    No modo local, os artigos entram pelo terminal do VS Code:

    npm run extrair -- "https://endereço-do-artigo"

    Depois, recarregue esta página.

    Bookmarklet

    Para salvar a página que você está lendo, inclusive com paywall ou login: clique no favorito → artigos e confirme na janelinha que abrir.

    Instalar (Zen, Firefox ou Chrome):

    1. Mostre a barra de favoritos: ⌘ ⇧ B.
    2. Arraste este botão até a barra: → artigos

    Se arrastar não funcionar: , clique com o botão direito na barra de favoritos → Adicionar favorito (Zen/Firefox) ou Adicionar página (Chrome), dê o nome → artigos e cole o código no campo do endereço (URL).

    Se o navegador avisar que bloqueou uma janela pop-up, permita pop-ups para aquele site.

    Token do GitHub

    Seus artigos ficam no repositório privado artigos-dados. Para ler e gravar lá, este navegador precisa de um token do GitHub com acesso só a esse repositório.

    O token fica guardado só neste navegador e é enviado apenas para api.github.com.
