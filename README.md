# Artigos

App pessoal de "ler depois", no espírito do Instapaper e do antigo Pocket.
Colo a URL de um artigo e ele é salvo inteiro, limpo (sem anúncios, menus nem
a formatação do site), para ler com conforto, marcar highlights, anotar e
buscar.

Publicado em https://denispacheco-prog.github.io/artigos/ (a partir do M4).
Faz parte da mesma família visual do
[reader](https://github.com/denispacheco-prog/reader) e do
[meus-bookmarks](https://github.com/denispacheco-prog/meus-bookmarks).

## Onde fica cada coisa

- **Este repo (público):** só o código do site e do extrator. Nunca texto de
  artigos de terceiros.
- **`artigos-dados` (privado):** artigos salvos, imagens, highlights, notas e
  índice de busca. Lido e gravado pelo site via API do GitHub, com token
  guardado no navegador.

## Arquivos

- `tokens.css` — cores, fontes e espaçamentos compartilhados com os outros
  projetos (moldura) e as opções da área de leitura.
- `DECISOES.md` — decisões de arquitetura aprovadas e o plano de etapas.
- `CLAUDE.md` — regras de trabalho para o Claude Code neste projeto.
